# siradel-oss.github.io

Organization site of [siradel-oss](https://github.com/siradel-oss) on GitHub
Pages, served at `oss.siradel.com`.

It only does two things:

- carries the `oss.siradel.com` domain, so every project site of the
  organization is served under it (`oss.siradel.com/<repository>/`);
- redirects the root to the main site, <https://sce.oss.siradel.com>.

Pages is deployed from the `main` branch, root folder.
